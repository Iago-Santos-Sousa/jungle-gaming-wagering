# Jungle Gaming: Distributed Wagering Processor

Serviço financeiro distribuído que processa transações de apostas (BET, WIN, LOSS, REFUND, ROLLBACK) recebidas via HTTP e SQS, com idempotência persistente, ledger imutável, inbox e transactional outbox.

Stack: Bun, TypeScript estrito, NestJS, MikroORM, PostgreSQL, SQS (MiniStack) e Docker Compose.

> Documentação completa de setup, comandos e arquitetura em construção.
